## AFB Chat Bot WordPress Plugin ( Conventional ChatBOT - NON-AI )

A WordPress plugin that allows your website visitors to get instant answers from a chatbot instead of a real human. All conversations can be forwarded to the site administrator through:

1. **Email**  
2. **WhatsApp** (via Twilio Addon)  
3. **SMS** (via Twilio Addon)

---

### Installation
1. **Download the ZIP file**.  
2. Log in to your WordPress Admin Panel.  
3. Navigate to **Plugins → Add New → Upload Plugin**.  
4. Upload the ZIP file and click **Install Now**.  
5. After installation, click **Activate**.

---

### Configuration
1. Go to **AFB Chat Bot Settings** in the WordPress admin menu.  
2. Fill out all required settings such as:  
   - Admin email  
   - Twilio Account SID / Auth Token  
   - WhatsApp number / SMS number (if using addons)  
   - Any chatbot configuration fields  
3. Save settings.

---

### Features
- Chatbot interface for frontend visitors  
- Option to forward full chat conversation to admin  
- Supports Email, WhatsApp, and SMS notifications  
- Twilio-based add-ons for WhatsApp and SMS delivery  
- Lightweight and easy to configure  

---

### Notes
- WhatsApp and SMS delivery require Twilio setup and credentials.  
- The plugin works with any WordPress theme.  

If you need help configuring the Twilio channels or customizing the chatbot behavior, feel free to ask.
